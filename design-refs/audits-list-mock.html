Mock notes: where each column comes from

Everything below is grounded in packages/shared/soa_shared/models/soa_models.py on main. Items marked ⚠ are not persisted on soa_lite_requests today and would need a join or a small schema addition.

UI elementSourceNotes
Brand, store URLbrand_name, store_urlRaw visitor input. Monogram falls back when no logo (same ladder as the report: brand_icon_url → logo.dev → favicon → monogram).
Lead email + flagsemail, report_email_sent_at, lead_notified_at"No email yet" = NULL. "Report ready · not sent" = complete + email NULL. "Queued" = email set, complete, report_email_sent_at NULL (sweep will pick it up).
Status pillstatus (LITE_STATUSES)pending → identifying_competitors → generating → running → complete | failed. "Partial read" is a UI state derived from the report payload, not a DB status. ⚠
Step / progress lineevents JSON (latest state/done event per task)Same event log the public status page reads. Query count from the queries/scoring tasks.
Durationcreated_at → updated_atApproximation; updated_at also moves on email PATCH. Exact end time is the report done-event ts.
Score⚠ not a columnAgentic Value Score is computed in the report payload (SCORER_VERSION). Options: (a) compute on read via the existing lite report builder, (b) add composite_score + scorer_version to soa_lite_requests when scoring finishes. (b) is cheaper for a list view and lets old-scorer rows show as "expired" like the report does.
Competitors + source tagcompetitor_names, competitor_source"mixed · 2 manual" = count of visitor-entered names (first ≤2 in the list are manual per the Stage 13 comment; verify ordering before relying on it).
Error traceerror_messageShown inline only for failed rows, same styling as the Cycles card error trace.
Full Analysis columnjoin soa_cycles.source_lite_request_id = soa_lite_requests.idShows the cycle code + status when a continuation exists; "Start" opens the existing NewCycleFlow prefilled from the audit (brand entity, competitor entity ids, study series).
Open report / copy linktokenPUBLIC_AUDIT_BASE_URL/r/{token}; status page /s/{token} while in progress. Never show ip_hash in the list.
Summary stripaggregates over the same tableLeads captured = email IS NOT NULL. Trend deltas are optional for v1.
Accessexisting Supabase JWT + org gateRows live under the "Parleo Lead Gen" org (organization_id); this view needs a new authed router, e.g. GET /api/lite-requests, separate from the public unauthenticated lane.
